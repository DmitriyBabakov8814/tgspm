## 🔧 Установка

### Требования
- **ОС:** Windows, macOS или Linux
- **Python:** версия 3.8 или выше
- **Интернет:** для загрузки зависимостей

### Шаги установки

#### 1️⃣ Скачивание зависимостей (Windows)
Дважды щелкните файл `install.bat` — он автоматически установит все необходимые библиотеки.

#### 2️⃣ Ручная установка (для опытных пользователей)
Откройте терминал в папке проекта и выполните:
```bash
pip install -r requirements.txt
```

#### 3️⃣ Первый запуск
Выполните в терминале:
```bash
python main.py
```

Приложение откроется в новом окне с интерфейсом.

## 🚀 Первый запуск

1. После запуска вы увидите окно приложения с левой боковой панелью (сайдбар)
2. На боковой панели 6 вкладок: Аккаунты, Контакты, Чаты, Рассылка, Парсер, История
3. Начните с вкладки **Аккаунты** — добавьте хотя бы один аккаунт
4. Затем добавьте контакты или чаты для рассылки
5. Переходите на вкладку **Рассылка** и запустите кампанию

## 👤 Вкладка Аккаунты

### Назначение
Добавление, импорт, проверка и управление Telegram-аккаунтами, которые будут использоваться для рассылки.

### Структура вкладки

Вкладка содержит 5 под-вкладок:

#### 📋 Под-вкладка "Все аккаунты"

**Что здесь видно:**
- Таблица со всеми добавленными аккаунтами
- Статус каждого аккаунта (активный, забанен, ожидает, не авторизован)
- Сколько сообщений отправлено в день и всего
- Последний раз аккаунт использовался
- Какой прокси привязан к аккаунту

**Колонки таблицы:**
| Колонка | Что означает |
|---------|-------------|
| **ID** | Внутренний номер аккаунта |
| **Телефон** | Номер телефона привязанного аккаунта |
| **Страна** | Страна кода телефона |
| **Статус** | Состояние аккаунта (см. таблицу ниже) |
| **День/Всего** | Сообщений отправлено сегодня / всего |
| **Последний сеанс** | Когда аккаунт в последний раз использовался |
| **Прокси** | Привязанный прокси-сервер (если есть) |

**Статусы аккаунтов:**
| Статус | Значение | Что делать |
|--------|----------|-----------|
| 🟢 **ACTIVE** | Аккаунт готов к работе | Используйте для рассылки |
| 🔴 **BANNED** | Аккаунт забанен (FloodWait или PeerFlood) | Дайте отдохнуть или удалите |
| 🟡 **COOLDOWN** | Временный лимит от Telegram | Подождите, аккаунт восстановится автоматически |
| 🟠 **UNAUTHORIZED** | Аккаунт не авторизован | Заново войдите или удалите |
| ⚪ **UNKNOWN** | Статус неизвестен | Нажмите "Проверить" |

**Кнопки на вкладке:**

- **✅ Проверить все** — проверяет статус всех аккаунтов (долгая операция)
- **🗑 Удалить забаненных** — автоматически удаляет все забаненные аккаунты
- **↻ Обновить** — перезагружает список без проверки
- **✓** (для каждого аккаунта) — проверяет статус конкретного аккаунта
- **✕** (для каждого аккаунта) — удаляет аккаунт из базы

---

#### 📥 Под-вкладка "Импорт .session"

**Что это?**
`.session` файлы — это файлы, содержащие авторизацию Telegram. Они создаются библиотекой Telethon.

**Как получить .session файлы:**
1. Используйте инструменты вроде Fragment, SMS-Activate или другие сервисы для получения сессий
2. Или экспортируйте из других программ, работающих с Telethon
3. Файлы должны иметь расширение `.session`

**Два режима импорта:**

##### Режим 1: Одиночный импорт
- Нажмите **"Выбрать файл"**
- Выберите один `.session` файл
- Введите **API ID** (от Telegram App)
- Введите **API Hash** (от Telegram App)
- Введите **номер телефона** привязанный к аккаунту
- Нажмите **"Импортировать"**

##### Режим 2: Массовый импорт
- Нажмите **"Выбрать папку"**
- Выберите папку с несколькими `.session` файлами
- Опционально: загрузите файл `accounts.txt` (если есть)

**Формат accounts.txt:**
```
api_id|api_hash|телефон|прокси
111111|a1b2c3d4e5f6g7h8|79999999999|socks5://user:pass@host:port
222222|b2c3d4e5f6g7h8i9|79888888888|socks4://host:port
```

Если `accounts.txt` не загружен, программа попросит вас ввести API ID и Hash отдельно.

---

#### 🔑 Под-вкладка "Session String"

**Что это?**
Session String — это длинная текстовая строка, которая содержит полную информацию о сессии Telegram. Её можно получить из различных источников.

**Как использовать:**
1. Вставьте одну или несколько session string в текстовое поле
2. Каждая строка — один аккаунт
3. Нажмите **"Добавить из строк"**

**Пример session string:**
```
1AgAOMRVBAAGO5NiQDzYyGcKa8u3QbHfMU7Cw3v2KU8x9Q8zGdC0zHq1...
```

**Где получить session string:**
- Fragment (фрагмент сессии)
- SMS-Activate или другие сервисы SMS
- Экспорт из других ботов или программ
- Сгенерировать через другие инструменты для Telethon

---

#### 📲 Под-вкладка "Ручной вход"

**Для чего:**
Если у вас есть телефон и API ID/Hash, вы можете напрямую авторизоваться в приложении.

**Шаги:**
1. Введите **номер телефона** (с кодом страны, например +79999999999)
2. Введите **API ID** (получить на my.telegram.org)
3. Введите **API Hash** (получить на my.telegram.org)
4. Нажмите **"Отправить SMS"**
5. Программа отправит вам код в Telegram
6. Введите полученный код
7. Аккаунт будет авторизован

**Как получить API ID и Hash:**
- Перейдите на https://my.telegram.org
- Войдите в свой аккаунт
- Перейдите в "API development tools"
- Создайте приложение (если не создано)
- Скопируйте **App ID** (это API ID)
- Скопируйте **App Hash** (это API Hash)

---

#### 🌐 Под-вкладка "Прокси"

**Для чего:**
Привязать прокси-серверы к аккаунтам для их маскировки и разделения трафика.

**Поддерживаемые форматы прокси:**

| Формат | Пример |
|--------|--------|
| SOCKS5 | `socks5://user:pass@host:port` |
| SOCKS5 простой | `socks5://host:port` |
| SOCKS4 | `socks4://host:port` |
| HTTP | `http://host:port` |
| Простой формат | `host:port:user:pass` |

**Как добавить прокси:**
1. Выберите аккаунт из списка
2. Введите адрес прокси в нужном формате
3. Нажмите **"Применить"**
4. Аккаунт будет использовать этот прокси при рассылке

**Советы по прокси:**
- Используйте разные прокси для каждого аккаунта
- Выбирайте прокси из одной страны с номером телефона
- Изменяйте прокси периодически для безопасности
- Проверяйте, что прокси рабочий перед использованием

## 👥 Вкладка Контакты

### Назначение
Создание и управление базой контактов для отправки личных сообщений (ЛС).

### Интерфейс вкладки

**Верхняя панель:**
- **🔍 Поиск** — найти контакт по имени или username
- **＋ Добавить** — добавить один контакт вручную
- **📥 Импорт CSV** — загрузить контакты из CSV файла
- **📤 Экспорт CSV** — сохранить все контакты в CSV файл
- **🗑 Очистить всё** — удалить все контакты (осторожно!)

**Таблица контактов:**

| Колонка | Что это |
|---------|--------|
| **Имя** | Полное имя контакта (первое + последнее имя) |
| **Username** | Юзернейм Telegram (@username) |
| **Телефон** | Номер телефона |
| **Источник** | Откуда был получен контакт (manual, parser, import, etc.) |
| **✕** | Кнопка удаления одного контакта |

### Как добавить контакты

#### Вариант 1: Добавить один контакт вручную
1. Нажмите **＋ Добавить**
2. Введите данные:
   - **Имя** — первое имя
   - **Фамилия** — последнее имя (опционально)
   - **Username** — юзернейм без @ (программа добавит @ автоматически)
   - **Телефон** — номер телефона (опционально)
3. Нажмите **Сохранить**

#### Вариант 2: Импортировать из CSV
1. Подготовьте CSV файл с колонками: `first_name,last_name,username,phone`
2. Нажмите **📥 Импорт CSV**
3. Выберите файл
4. Контакты будут добавлены в базу

**Пример CSV:**
```csv
first_name,last_name,username,phone
Иван,Петров,ivan_petrov,+79999999999
Мария,Сидорова,maria_sid,+79888888888
```

#### Вариант 3: Получить контакты через парсер
Используйте вкладку **Парсер** для автоматического сбора контактов из комментариев постов.

### Как работать с контактами

- **Поиск** — введите часть имени или username в поле поиска, список будет фильтроваться в реальном времени
- **Удаление** — нажмите ✕ напротив контакта
- **Экспорт** — сохраните текущий список в CSV файл для резервной копии
- **Статистика** — внизу показано общее количество контактов

## 💬 Вкладка Чаты

### Назначение
Управление базой групп и каналов, для отправки сообщений в чаты.

### Интерфейс вкладки

**Левая часть — список чатов:**
- **Таблица** с информацией о каждом чате
- **Кнопки**: Обновить, Удалить выбранные
- **Статистика** чатов

**Правая часть — добавление чатов:**
- **Форма добавления** вручную
- **Авто-поиск** чатов по ключевому слову

### Структура таблицы чатов

| Колонка | Что это |
|---------|--------|
| **Флажок** | Для выделения нескольких чатов (удаления) |
| **Название** | Название группы или канала |
| **Username** | Публичный юзернейм чата |
| **Тип** | group (группа), channel (канал), supergroup (супергруппа) |
| **Участников** | Приблизительное количество участников |

### Как добавить чат вручную

1. В правой панели заполните форму:
   - **Username или ID чата** — например `@mygroup` или ID
   - **Название** — как вы хотите его называть в программе
   - **Тип** — выберите из выпадающего списка
2. Нажмите **Добавить**

### Как найти и добавить чаты автоматически

1. В поле **"Авто-поиск чатов"** введите ключевое слово (например "бизнес", "маркетинг")
2. Нажмите **🔍 Найти и добавить**
3. Программа найдёт публичные чаты с этим ключевым словом
4. Выберите интересующие чаты и добавьте их

### Типы чатов

| Тип | Описание |
|-----|----------|
| **group** | Обычная закрытая группа |
| **channel** | Канал (только администраторы могут писать) |
| **supergroup** | Большая группа с расширенными функциями |

### Статусы чатов

- **Активный** (зелёный) — можно писать в этот чат
- **Неактивный** (серый) — доступ ограничен или бот удалён
- **Ошибка** — проблема при отправке

## 📤 Вкладка Рассылка

### Назначение
Основной функционал — отправка сообщений в контакты или чаты с использованием нескольких аккаунтов.

### Структура вкладки

Разделена на две части:
- **Левая** — настройки рассылки
- **Правая** — прогресс и результаты

### Левая панель: Настройки рассылки

#### 1. Название кампании
Введите название для вашей рассылки (например "Рассылка Июль 2024"). Используется для логирования.

#### 2. Тип рассылки (📌)
Выберите один из трёх режимов:

**👥 По контактам** — Отправляет личные сообщения каждому контакту из базы
- Лучший вариант для персональных предложений
- Используется для привлечения клиентов

**💬 По чатам** — Отправляет сообщение один раз в каждый чат
- Для публичных объявлений
- Для информирования больших аудиторий

**🔍 ЛС спарсенным** — Отправляет ЛС контактам, собранным парсером
- Используется вместе с функцией парсера
- Контакты собираются из комментариев постов

#### 3. Текст сообщения
Введите текст, который будет отправляться.

**Переменные для персонализации:**
```
{first_name}   — первое имя получателя
{last_name}    — фамилия получателя
{username}     — юзернейм получателя
```

**Пример сообщения:**
```
Привет, {first_name}! 👋

Я нашёл отличное предложение для {username}.
Если интересно, пиши сюда!
```

#### 4. Спин-текст (🔄)
Функция для создания вариаций сообщения (антиспам).

**Как использовать:**
Используйте синтаксис `{вариант1|вариант2|вариант3}`

**Пример:**
```
{Привет|Здравствуйте|Добрый день}, {first_name}!

Предлагаю {горячее|интересное|выгодное} предложение.
```

При отправке каждому пользователю будет отправлен уникальный вариант сообщения.

#### 5. Медиа (📎)
Прикрепите картинку, видео или другой файл к сообщению.

**Как использовать:**
- Нажмите **Прикрепить** — выберите файл
- Он будет отправляться со всеми сообщениями
- Удалите медиа кнопкой **✕**

#### 6. Антибан настройки (🛡)

**Задержка мин (сек)** — минимальная пауза между сообщениями (например, 5 секунд)

**Задержка макс (сек)** — максимальная пауза (например, 15 секунд)
- Реальная пауза будет случайной между мин и макс (от 5 до 15 сек в примере)

**Сообщ/аккаунт** — сколько сообщений может отправить один аккаунт перед переключением на другой (например, 30)

**Ротация аккаунтов** — автоматическое переключение между аккаунтами
- ✅ Рекомендуется включить (защита от бана)
- Каждые N сообщений программа меняет аккаунт

#### 7. Аккаунты для рассылки (👤)

**Используйте все активные аккаунты** — отправляет через все рабочие аккаунты

**Выбрать определённые** — уберите флажок выше и выберите конкретные аккаунты:
- Установите галочки рядом с нужными аккаунтами
- Рассылка будет только через них
- Остальные будут игнорироваться

### Правая панель: Запуск и прогресс

**Кнопки:**
- **▶️ Начать рассылку** — запускает кампанию
- **⏹ Остановить** — прерывает текущую рассылку
- **↻ Обновить результаты** — обновляет статистику

**Информация о ходе:**
- **Статус** — что сейчас происходит
- **Прогресс-бар** — процент завершения
- **Статистика:**
  - Отправлено ✓
  - Ошибок ✗
  - Осталось
  - Время выполнения

**Финальные результаты:**
После завершения вы увидите:
```
Рассылка завершена!
Всего: 1000
Успешно: 950
Ошибок: 50
Время: 2ч 30мин
```

## 🔍 Вкладка Парсер

### Назначение
Автоматическое сбор контактов из комментариев постов в каналах + отправка им ЛС + приглашение в канал.

### Структура вкладки

Разделена на три части:

### ➜ Часть 1: Парсинг канала (🔍)

**Как это работает:**
Программа берёт N последних постов из указанного канала и собирает всех, кто прокомментировал эти посты.

**Параметры:**

**Канал-источник:**
- Введите юзернейм канала (например `@channel_name`)
- Или полный URL (`t.me/channel_name`)
- Программа автоматически преобразует в нужный формат

**Кол-во постов для парсинга:**
- Сколько последних постов обработать (например 30)
- Чем больше — тем больше контактов найдём, но дольше парсинг

**Пропускать ботов:**
- ✅ Включено — не добавляет учётные записи ботов

**Добавить в контакты:**
- ✅ Включено — добавляет найденные контакты в базу
- ❌ Отключено — только просмотр, без сохранения

**Запуск парсинга:**
- Нажмите **🔍 Начать парсинг**
- Внизу покажется прогресс-бар

## 🛡 Антибан система

### Как она работает

Программа имеет встроенную защиту от бана в Telegram:

#### 1. Случайные задержки
- Между каждым сообщением добавляется случайная пауза
- Минимальная и максимальная задержка задаются в настройках
- Это имитирует естественное поведение

#### 2. Ротация аккаунтов
- После отправки N сообщений с одного аккаунта происходит переключение на другой
- Telegram видит разные IP, разные аккаунты, разную активность
- Сложнее определить автоматизацию

#### 3. Автоматический Cooldown при FloodWait
- Если Telegram отправляет ошибку FloodWait ("слишком быстро")
- Программа автоматически ждёт и повторяет попытку
- Вы будете уведомлены о задержке

#### 4. Длительный Cooldown при PeerFlood
- PeerFlood — более серьёзное ограничение
- Программа добавляет 5-минутный перерыв
- Помечает аккаунт как "в ожидании"
- Аккаунт восстанавливается автоматически

#### 5. Автоматическое определение забаненных аккаунтов
- При любой ошибке программа проверяет, не забанен ли аккаунт
- Забаненные аккаунты помечаются красным
- Они исключаются из дальнейшей рассылки

#### 6. Ежедневный счётчик
- Счётчик отправленных сообщений сбрасывается каждый день в полночь
- Отслеживается безопасный дневной лимит для каждого аккаунта

## 💡 Советы и трюки

### ✅ Как безопасно добавить аккаунты

1. Добавляйте аккаунты в небольших количествах (5-10 за раз)
2. Дайте им отдохнуть 1-2 часа после добавления
3. Проверьте их статус перед первой рассылкой
4. Проведите тестовую рассылку на 5-10 контактов
5. Если всё хорошо — начинайте полную кампанию

### ✅ Как избежать бана

1. **Используйте разные прокси** для каждого аккаунта
2. **Устанавливайте случайные задержки** (не одинаковые паузы)
3. **Варьируйте текст сообщений** (используйте спин-текст)
4. **Не отправляйте сразу всё** — растяните на несколько часов/дней
5. **Периодически меняйте аккаунты** в ротации
6. **Не повторяйте одно и то же сообщение** много раз подряд
7. **Следите за лимитами Telegram** — они строже для новых аккаунтов

### ✅ Как сэкономить время

1. **Импортируйте контакты массово** (CSV или .session файлы)
2. **Подготовьте текст заранее** с переменными
3. **Используйте спин-текст** — одно сообщение, много вариантов
4. **Настройте ротацию** — программа сама будет переключаться
5. **Запланируйте заранее** — добавьте все контакты, потом запустите рассылку

### ✅ Интерпретация статусов аккаунтов

| Статус | Что произошло | Решение |
|--------|---------------|--------|
| ACTIVE | Аккаунт рабочий | Используйте |
| COOLDOWN (жёлтый) | Telegram лимит | Подождите ~5-10 мин |
| BANNED (красный) | Временный или постоянный бан | Дайте отдохнуть 24+ часа или удалите |
| UNAUTHORIZED | Сессия умерла | Переавторизируйтесь или удалите |
| UNKNOWN | Не проверен | Нажмите "Проверить" |

### ✅ Как работать с парсером эффективно

1. **Выберите качественный канал** — много активных комментариев
2. **Парсьте 30-50 последних постов** — баланс между качеством и скоростью
3. **Включите "Добавить в контакты"** — контакты сохранятся в БД
4. **Выключите "Пропускать ботов"** только если нужны именно боты
5. **Сразу после парсинга** проверьте количество найденных контактов
6. **Отправляйте ЛС в течение 1-2 часов** после парсинга — они "горячие"

### ✅ Мониторинг рассылки

1. **Смотрите прогресс-бар** в реальном времени
2. **Обращайте внимание на ошибки** — если много, остановитесь
3. **Следите за статусами аккаунтов** во время рассылки
4. **После завершения проверьте статистику** в вкладке История
5. **Анализируйте результаты:**
   - Процент успеха
   - Типы ошибок
   - Какие аккаунты работали лучше

### ✅ Экспорт и резервные копии

1. **Регулярно экспортируйте контакты** в CSV
2. **Сохраняйте текущие кампании** (скриншоты параметров)
3. **Ведите лог** — какие рассылки были, какие результаты
4. **Храните список рабочих прокси** отдельно
5. **Сделайте резервную копию** папки `sessions/` с .session файлами

### ✅ Решение проблем

**Программа вылетает:**
- Переустановите зависимости: `pip install -r requirements.txt`
- Обновите Python до версии 3.8+
- Проверьте, что у вас есть интернет

**Аккаунты не добавляются:**
- Проверьте API ID и Hash
- Убедитесь, что .session файл не повреждён
- Попробуйте ручной вход

**Рассылка не работает:**
- Проверьте статус аккаунтов (они должны быть ACTIVE)
- Убедитесь, что выбрали хотя бы один аккаунт
- Проверьте наличие контактов или чатов
- Проверьте подключение к интернету

**Ошибка FloodWait:**
- Это нормально — программа автоматически ждёт
- Увеличьте задержку между сообщениями
- Используйте меньше сообщений на аккаунт

**Аккаунты забаниваются часто:**
- Используйте более длинные задержки
- Добавьте разные прокси
- Варьируйте текст больше
- Используйте старые аккаунты с историей

## 🎓 Расширенные техники

### Техника 1: Волновая рассылка
1. Запустите рассылку на 5 контактов
2. Подождите 1 час, проверьте результаты
3. Если хорошо — запустите на 50 контактов
4. Подождите 2 часа
5. Если хорошо — полная рассылка на всех

**Выигрыш:** Видно проблемы на малом уровне, не потеряете всех контактов.

### Техника 2: Комбо парсер + ДМ + Инвайт
1. Запустите парсер канала (30 постов)
2. Отправьте ЛС всем найденным контактам (50% отправляется, 50% в очереди)
3. Пригласите в ваш канал (только тех, кто ответил)
4. Результат: квалифицированная аудитория в вашем канале

### Техника 3: A/B тестирование
1. Разделите контакты пополам
2. Первой половине отправьте текст A
3. Второй половине — текст B
4. Сравните результаты (ответы, рост, реакции)
5. Выберите лучший вариант для масс-рассылки

### Техника 4: Планомерный прогрев аккаунтов
1. День 1: Добавьте аккаунты, дайте отдохнуть
2. День 2: Отправьте по 5 ЛС с каждого, проверьте статусы
3. День 3: Отправьте по 20 ЛС
4. День 4: Полная рассылка

**Выигрыш:** Аккаунты не блокируются, риск минимален.
